# 来源与证据策略

## 来源优先级

1. 官方官网 / 官方帮助中心 / 官方产品页
2. 主流媒体评测
3. 用户论坛 / Reddit / 官方社区
4. 权威指南 / 论文数据库 / 行业规范

## 使用规则

### 官方来源

适合回答：

- 功能叫什么
- 官方怎么定义
- 官方展示方式是什么

### 用户评论

适合回答：

- 用户喜欢什么
- 用户吐槽什么
- 常见争议点是什么

不要写成：

- “所有用户都……”
- “用户普遍都……”

更稳妥写法：

- “公开讨论中的共性反馈是……”
- “部分用户认为……”

### 科学/行业依据

当主题涉及健康、医学、运动科学、法律、金融等领域时，要优先查权威来源。

优先：

- WHO
- CDC
- HHS
- ACSM
- AHA
- PubMed

## 表达边界

必须避免：

- 把相关性写成因果
- 把消费者指标写成医疗诊断
- 把少量评论样本写成普遍定量结论

推荐表达：

- “与……相关”
- “更接近……建议”
- “公开评论中的共性反馈”
- “从现有指南/文献看”
