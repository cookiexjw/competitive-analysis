# 输出模板

## 模板一：研究底稿

适合知识沉淀和继续加工。

### 推荐结构

1. 研究结论先看
2. 竞品全景概览
3. 重点竞品拆解
4. 共性洞察
5. 产品机会点
6. 候选指标/能力框架
7. 科学依据或行业依据
8. 参考来源

### 重点竞品拆解统一字段

- 名称
- 官方含义
- 主要输入因子/机制
- 输出形式
- 用户评论摘要
- 页面截图
- 对本产品的启发
- 风险点

## 模板二：导出版

适合评审、汇报、快速阅读。

### 推荐结构

1. 先说结论
2. 角色分工或问题定义
3. 竞品全景
4. 重点竞品图文拆解
5. 共性模式
6. 机会点
7. 最终建议

### 图文小节推荐结构

每个重点竞品尽量按以下结构组织：

1. 为什么重要
2. 页面示意
3. 设计观察
4. 对我们的启发
5. 风险提醒

## HTML 查看版要求

如果用户要求“打开直接看图”，生成 HTML 查看版时要做到：

- 图片尺寸统一
- 同类小图可并排
- 图片可点击放大
- 图片标题与正文关联紧密
- 空图位明确标注“暂无图片”
